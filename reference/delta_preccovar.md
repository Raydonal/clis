# Perturbation matrix for the precision-covariate scheme

Perturbation matrix for the precision-covariate scheme

## Usage

``` r
delta_preccovar(object, p = 1L)
```

## Arguments

- object:

  A fitted BEZI/BEOI `gamlss` model.

- p:

  Index of the perturbed covariate in the precision design matrix.

## Value

A list with the full `Delta` and its blocks.
