# Perturbation matrix for the discrete-covariate scheme

Perturbation matrix for the discrete-covariate scheme

## Usage

``` r
delta_disccovar(object, p = 1L)
```

## Arguments

- object:

  A fitted BEZI/BEOI `gamlss` model.

- p:

  Index of the perturbed covariate in the inflation design matrix.

## Value

A list with the full `Delta` and its blocks.
