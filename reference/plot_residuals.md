# Diagnostic residual plots for a BIc model

Diagnostic residual plots for a BIc model

## Usage

``` r
plot_residuals(object, label_top = 3L)
```

## Arguments

- object:

  A fitted BEZI/BEOI `gamlss` model.

- label_top:

  Integer; number of extreme points to label.

## Value

Invisibly returns a list of residual vectors.
