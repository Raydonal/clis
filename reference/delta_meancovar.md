# Perturbation matrix for the mean-covariate scheme

Perturbation matrix for the mean-covariate scheme

## Usage

``` r
delta_meancovar(object, p = 1L)
```

## Arguments

- object:

  A fitted BEZI/BEOI `gamlss` model.

- p:

  Index of the perturbed covariate in the mean design matrix.

## Value

A list with the full `Delta` and its blocks.
